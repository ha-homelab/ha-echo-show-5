Проект превращает **Amazon Echo Show 5 второго поколения (2021), кодовое имя `cronos`**, в голосовую точку Home Assistant, часы, экран камер по движению и управляемый медиатерминал. В репозитории — инструменты конверсии под наблюдением оператора, патчи, интеграции и инструкции восстановления. Прошивки, APK, личные модели активации и домашние учётные данные сюда не входят.

Начните с [wiki проекта](docs/wiki/Home.md). Для заводского устройства предназначена [пошаговая инструкция конверсии](docs/runbook.md), для уже установленного Android — [обновление и восстановление](docs/wiki/Installation-and-recovery.md). **Не повторяйте разблокировку уже сконвертированного устройства.** Подробные технические инструкции ведутся на английском; эта страница — русскоязычная точка входа.

## 20 октября: проверено управление голосовым движком на первом Show

**Первый Show работает на `myshka.9` / `7009` с «Привет, мышка» и «Hey Jarvis».**
Порог Myshka сохранён на **0,50**; у Jarvis — собственное среднее по пяти
вычислениям **> 0,97**. Один микрофон обслуживает обе фразы и отдельную команду
Stop. Обновление ждёт закрытия прежнего детектора перед заменой и не запускает
захват микрофона при отключённой основной фразе.
При ошибке одного этапа остановки эта сборка выполняет остальные этапы освобождения ресурсов.

Прошли **62 JVM-теста** и **шесть тестов Android**. На устройстве проверены
смена настроек без перезапуска приложения, отключение основной фразы,
**три цикла фактического закрытия и открытия микрофона** и перезапуск приложения.
Настройки HA, проверка HTTPS, разрешения и экран сохранены. **Второй Show
недоступен; последняя проверенная версия — `.4`.** Проверка живой речи остаётся открытой.

## Возможности

- **Голосовой Assist:** точная ONNX-модель **«Привет, мышка»** с порогом **0,50** и необязательная встроенная **«Hey Jarvis»** с отдельным калиброванным условием по нескольким вычислениям. Прежний режим с двумя моделями microWakeWord доступен отдельно. Приватные модели не распространяются. [Голос и модели](docs/wiki/Voice-and-wake-words.md).
- **Интерфейс для пяти дюймов:** крупные часы, полноэкранное видео Front/Porch по движению, ручной просмотр с ограничением времени и возврат к часам. Пропорции сохраняются; видео появляется после готовности кадра, без растянутой системной кнопки Play. [Экран](docs/wiki/Display-media-and-calls.md).
- **Управление через HA:** объявления, музыка, заданные телеканалы, наш клиент OTT-play FOSS на Capacitor, отдельная веб-версия OTT и необязательный OttPlayer. Home/Stop завершает текущую управляемую активность. [Удалённое управление](docs/remote-endpoint.md).
- **Звонки через свою Jitsi:** фиксированная комната, явно выбранный режим входа, передача микрофона и восстановление после звонка. Экспериментальный интерком HA — отдельный путь. [Звонки](docs/wiki/Display-media-and-calls.md#jitsi-and-intercom).
- **Выбор голосового сервиса:** Homeway; независимый облачный маршрут FCC; либо локальный диалог и Silero с облачным распознаванием FCC. Ассистент выбирается для конкретного устройства, автоматического переключения при сбое нет. [Переключение](docs/wiki/Voice-and-wake-words.md#choose-and-switch-an-assistant).
- **Языки:** входные README на английском, русском, немецком, испанском и французском; собственная настройка языка интерфейса часов. Язык экрана не меняет язык распознавания или фразу активации. [Покрытие локализацией](docs/wiki/Localization.md).

## Совместимость и подготовка

Поддерживается **только Show 5 Gen2 / `cronos`**. Образы и инструкции Echo Dot/EchoLocal, Show 5 Gen1 и Show 8 не взаимозаменяемы.

```text
Заводской cronos → amonet-cronos 2.0.1 → TWRP → проверенная внешняя копия
                → LineageOS 18.1 v0.4 / Android 11 → Companion + VACA по желанию
```

Разблокировка изменяет загрузочную цепочку **до первой резервной копии**. Установка Android заменяет Fire OS/Alexa и форматирует данные. Наличие копии не означает, что универсальное восстановление заводской системы проверено. Нужны обычный **блок питания**, micro-USB **кабель данных**, физический Synology **x86_64** с Docker/Python 3.8+/SSH и местом для копий, рабочий компьютер с Python/SSH/rsync и доступный сервер HA. USB не заменяет блок питания. Артефакты скачиваются и проверяются отдельно по инструкции.

После подготовки хоста по [runbook](docs/runbook.md) эти команды только читают состояние:

```bash
python3 scripts/remote.py preflight
python3 scripts/remote.py inventory
```

Для действий выбирайте **наблюдаемый физический USB-порт и полный серийный номер**, а не «первый Echo». Запись выполняется отдельными командами с проверками; подключение кабеля её не запускает.
