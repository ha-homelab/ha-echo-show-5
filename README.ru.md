# Echo Show 5 Gen2 → Android → Home Assistant

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md)

Это переведённый обзор и маршрут начала работы. Подробные инструкции и команды пока поддерживаются на английском; ссылки ведут к ним. Язык этого README не меняет язык распознавания, голос ответа или стартовую фразу.

Инструменты и пошаговая инструкция для **Echo Show 5 второго поколения (2021), codename `cronos`**. После установки Android устройство может показывать панель HA через Companion и работать как голосовой клиент с отдельно настроенным Assist. Это самостоятельный путь для дисплея, не прошивка EchoLocal или EchoMuse для Dot.

![Echo Show 5 Gen2 → Android → Home Assistant](docs/assets/architecture.svg)

## С чего начать

1. Подтвердите модель **Gen2 / cronos**. Нужны штатный блок питания, micro-USB кабель с передачей данных, физический Synology x86_64 с Docker и Python 3.8+, а также рабочая станция с Python, SSH и rsync.
2. Начните с [инструкции установки](docs/runbook.md): настройте адрес SSH, загрузите и проверьте закреплённые артефакты, подготовьте контейнер. Выберите физический USB-порт и полный наблюдаемый серийный номер; не выбирайте «первое найденное» устройство.
3. Выполните отдельные этапы: amonet-cronos 2.0.1 → TWRP → проверенная внешняя резервная копия → LineageOS 18.1 v0.4 / Android 11 → Companion 2026.8.4 minimal. Если TWRP уже подтверждён, повторная разблокировка не нужна.
4. Подключите Android к Wi-Fi, войдите в HA через Companion, выберите панель и проверьте разрешения. Для голоса отдельно настройте язык и этапы Assist по [руководству Android и HA](docs/android-and-home-assistant.md). VACA — дополнительный путь постоянного прослушивания стартовой фразы.
5. По отдельности добавляйте [панель](docs/show-dashboard.md), [голосовые команды музыки](docs/native-voice-controls.md), камеру или интерком. Сначала проверьте основной режим, затем каждую дополнительную функцию.

## Границы и проверка

Разблокировка изменяет загрузочную цепочку до первой резервной копии. Установка Android заменяет Fire OS и Alexa и форматирует данные. Raw-копия создаётся после разблокировки, не включает RPMB и не является универсальной гарантией восстановления заводского состояния. Исторические результаты и непроверенные сценарии перечислены в документе приёмки; установленное приложение не доказывает акустическую точность или многодневную стабильность. Камера, интерком и Jitsi имеют собственные ограничения. Не переносите эту процедуру на Dot или другие поколения Show.
